# Categorical-cell checks: results (H11)

10 public tables × 5 fresh seeds (50 runs), up to 400 rows each (penguins: 344; tips: 244). 3% of categorical cells were swapped to a different level drawn from the same column (plausible for the column, not a typo). Precision@k vs the per-dataset best of 5 baselines (frequency, logistic, random forest, kNN, HGB; chosen after the fact). Generated by `benchmarks/summarize_categorical.py`.

**H11 supported:** TabPFN-3.5 beats the best baseline on **10/10** datasets; mean precision@k gain +0.062 [+0.042, +0.088]; one-sided Wilcoxon p = 0.00098.

Notes: a swap to a category that is ordinary for the column and also compatible with the rest of the row is undetectable by any method, so absolute precision is lower than for numeric cells. Auto MPG was used for a development smoke test and is excluded. The typo hint ("possible typo of …") is a separate string heuristic and is not part of this test.

Provenance: `proofread/core.py` was edited after launch (a guard for tables where a numeric column has no other columns to learn from).
