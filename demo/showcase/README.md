# TabLint product showcase

[Watch or download the approved video](TabLint-demo.mp4). 87.77 seconds · 1920×1080 · 30 fps · original music and interaction sounds.

This is a stylized animation of the real VS Code CSV workflow, not a live screen recording. The 4,354 lb Civic example, 1,877 lb expectation, 1,720–2,034 lb interval and 0 → 70 horsepower correction come from the stored Auto MPG numerical report. The specific USA → Japan suggestion is an illustrative categorical workflow; it is not a captured model run. The engine implements categorical checks and its measured results are documented separately in [categorical results](../../docs/CATEGORICAL_RESULTS.md).
